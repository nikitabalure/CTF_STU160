CTF_STU160 – Capture the Flag Challenge

This repository contains my solution for the book review Capture the Flag (CTF) challenge.
Problem Summary
We are given two datasets:
- `books.csv` (book metadata)
- `reviews.csv` (reviews for those books)

The goal is to:
1. Find a “manipulated” book whose reviews contain a hidden hash based on my ID `STU160`.
2. Extract three flags (FLAG1, FLAG2, FLAG3) using hashing and model explanations.
3. Submit code, explanation, and flags in this repository.
